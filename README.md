# 💈 Pride Barbers - Dashboard de Gestão Fullstack

![Banner ou Print Principal](https://imgur.com/TuuDma9)

## 📖 Sobre o Projeto

O **Pride Barbers Dashboard** é um sistema completo de gestão para barbearias, desenvolvido para modernizar o controle de agendamentos, fluxo de caixa e métricas de desempenho.

O projeto foi construído utilizando uma arquitetura **Fullstack** (Frontend e Backend separados), simulando um ambiente real de produção com autenticação segura e dados dinâmicos.

---

## 🚀 Tecnologias Utilizadas

### Frontend (Cliente)

- **React.js (Vite):** Performance e componentização.
- **Chart.js (React-Chartjs-2):** Gráficos interativos e dinâmicos.
- **Axios:** Consumo de API RESTful.
- **CSS3 Moderno:** Estilização com Glassmorphism, Neon Glow e Grid Layout responsivo.
- **Lucide React:** Ícones leves e modernos.

### Backend (Servidor)

- **Node.js & Express:** API REST rápida e escalável.
- **JWT (JSON Web Token):** Sistema de autenticação e segurança de rotas.
- **CORS:** Controle de acesso entre domínios.
- **In-Memory Database:** Persistência de dados volátil para prototipagem rápida.

## ✨ Funcionalidades Principais

### 1. 📊 Dashboard Analítico

Visão geral do negócio em tempo real.

- KPIs de Faturamento, Total de Clientes e Serviços.
- **Gráfico Dinâmico:** Se adapta automaticamente ao horário de funcionamento configurado (ex: 09h às 20h).

### 2. 📅 Gestão de Agendamentos

Controle total do fluxo de clientes.

- **CRUD Completo:** Criar, Listar e Excluir agendamentos.
- **Status em Tempo Real:** Mude de "Agendado" para "Concluído" instantaneamente.
- **Filtros Avançados:** Busque por nome, serviço ou status.

### 3. ⚙️ Configurações Dinâmicas

O sistema se adapta à barbearia, não o contrário.

- Defina o horário de abertura e fechamento (impacta os gráficos).
- Edite dados da empresa e perfil do usuário (nome/avatar).
- Gerencie o catálogo de serviços e preços.

### 4. 📄 Relatórios

- Filtre métricas por **Hoje**, **Semana** ou **Total**.
- Exportação de dados (visualização pronta para impressão).
